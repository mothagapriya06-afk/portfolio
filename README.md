# Mothagapriya Sankaran — Portfolio Refresh

A responsive static portfolio refresh built with HTML, CSS and JavaScript for GitHub Pages. It includes custom mockup presentation images, project filters, accessible case-study dialogs, responsive navigation and concept-project disclaimers.

## Preview locally

Open `index.html` in a browser. For a local server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Deploy to the existing GitHub Pages site

1. Download and unzip `portfolio-refresh.zip`.
2. Review `index.html`, especially email, LinkedIn, experience claims and project descriptions.
3. Open the repository that currently publishes `mothagapriya06-afk.github.io/portfolio/`.
4. Back up the current repository contents.
5. Upload the contents of this folder into the repository's publishing folder (often the repository root or `/docs`, depending on its Pages settings). Keep the `assets` folder structure intact.
6. Commit the change and wait for GitHub Pages to publish.

This package does not automatically modify the live repository. Confirm all personal details, claims and project labels before publishing.

## Mockup presentation update

- `assets/images/hero-devices.jpg` is a tight crop of the original hero board (devices only, so the headline is not duplicated).
- Original mockups are preserved in `assets/images/originals/` and can be deleted before publishing if you wish.
- The Invictus screen was retouched to remove an unrelated phone that overlapped the original render, and the browser-frame URLs (`app.lumen-finance.com`, `invictus.tech`) are placeholders baked into the artwork.
